# Maze Escape: A Pathfinding Game Using DFS, BFS and Backtracking Algorithms

## 1. Introduction
Maze Escape is a Python-based pathfinding game developed to demonstrate the application of Data Structures and Algorithms (DAA) in solving maze problems.

The game provides a graphical user interface (GUI) using the Tkinter library. It allows users to explore a maze and understand how different pathfinding algorithms find a route from the starting point to the exit.

## 2. Technologies Used
- Python
- Tkinter (GUI)
- Visual Studio Code

## 3. Algorithms Used

**1. Depth First Search (DFS)**

DFS explores a path as deeply as possible before backtracking to explore other paths.

**2. Breadth First Search (BFS)**

BFS explores the maze level by level and finds the shortest path in an unweighted maze.

**3. Recursive Backtracking**

This algorithm is used to generate the maze by exploring different directions and backtracking when a path cannot be continued.

## 4. Features
- Graphical user interface using Tkinter.
- Maze generation using Recursive Backtracking.
- Pathfinding using DFS and BFS algorithms.
- Visual representation of maze-solving techniques.
- Demonstrates practical applications of Data Structures and Algorithms.

## 5. Project Files

- `main.py` – Main Python program.
- `maze_escape.py` – Maze Escape implementation.
- `bfs_version.py` – BFS algorithm implementation.
- `dfs_version.py` – DFS algorithm implementation.

## 6. Requirements
- Python 3.x
- Tkinter library
- Visual Studio Code or any Python-supported IDE.

## 7. How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```

5. The game window will open.

Maze Escape demonstrates how different Data Structures and Algorithms can be applied to solve real-world pathfinding problems. It provides an interactive way to understand maze generation, searching techniques and backtracking.
